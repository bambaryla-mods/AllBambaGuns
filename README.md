# Guns For All Post-Medieval Tech Levels

A RimWorld mod that fills the gaps in vanilla's gun lineup: ballistic guns past Industrial, charge guns before and after Spacer, and disposable launchers for every tier. Supports Combat Extended and Beyond Our Reach.

- Website, with every gun's stats: https://bambaryla-mods.github.io/AllBambaGuns/
- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3782391721

## Layout

| Path | What |
|---|---|
| `Defs/`, `Patches/` | Always loaded: the guns, research, BOR integration |
| `Launchers/` | Disposable launchers, without Combat Extended |
| `CE/` | Combat Extended versions of the guns, ammo and launchers |
| `MuzzleFlash/` | Muzzle flashes, when the Muzzle Flash mod is active |
| `site/` | The website generator (not part of the mod, see `site/README.md`) |
